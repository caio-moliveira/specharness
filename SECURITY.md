# Política de Segurança

Encontrou uma vulnerabilidade? **Não abra issue pública.**
Reporte via GitHub Security Advisories (aba Security → Report a vulnerability).
Resposta inicial em até 72h. Divulgação coordenada após correção.

Escopo de atenção especial: manuseio de credenciais de conexões (trackers,
git providers, LLM), execução de hooks e conteúdo de specs importadas.
