# practices/ — boas práticas oficiais (Claude Code)

Cada prática é um arquivo markdown com frontmatter:

```yaml
---
id: claude-code/claude-md-conciso
source_url: https://...      # doc oficial da Anthropic
accessed: 2026-07-25
applies_to: [CLAUDE.md]
---
```

Sem `source_url`, a prática não entra (ADR-004). O PR de atualização de
prática é a good first issue canônica do projeto.
